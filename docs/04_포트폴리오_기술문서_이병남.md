# 4. 포트폴리오 기술 문서 (Technical Dossier)
### 자율주행 로보틱스 &amp; 온디바이스 엣지 비전 AI 심층 시스템 엔지니어링 명세

## 1. 자율주행 SLAM, Voronoi 경로 계획 및 15ms 제어권 중재 아키텍처
> **센서 융합 SLAM(LiDAR/IMU/Odometry), EKF 상태 추정, Voronoi 무충돌 경로 계획, 3D LiDAR 화물 하역, 15ms 기능 안전 제어권 중재기 명세 (비중 65%)**

### 1.1 EKF &amp; MCL 기반 센서 융합 상태 추정 (State Estimation)
- **기술적 당면 과제**: 실내 물류창고나 제조 현장은 GPS가 음영(Denied)되며, 바퀴 미끄러짐이나 지면 요철로 인해 단일 오도메트리 사용 시 위치 오차가 시간에 따라 기하급수적으로 발산함.
- **아키텍처 설계 및 해결책**: IMU 고주파(100Hz+) 관성 측정값과 휠 인코더, 2D LiDAR 스캔 오도메트리를 **확장 칼만 필터(EKF)**로 융합. 시스템의 비선형 모션 모델을 1차 테일러 급수로 선형화하여 자코비안(Jacobian) 행렬을 실시간 갱신하고, 센서 공분산(Covariance) 행렬 튜닝을 통해 센서 노이즈를 효과적으로 필터링. 초기 전역 위치 추정을 위해 **몬테카를로 위치추정(MCL)** 파티클 필터를 적용하여 납치 로봇(Kidnapped Robot) 상황에서도 안정적 복구 실증.

### 1.2 2D/3D 점유격자지도 (Occupancy Grid Mapping) &amp; FastSLAM
- **무인프라 브라운필드 맵핑**: 반사 마커나 고정 비콘을 설치하기 어려운 기존 물류 환경에서, LiDAR의 광선 추적(Ray-tracing) 알고리즘을 활용해 공간을 $P(\text{occupied} | z_{1:t})$ 확률 기반 점유 격자로 모델링.
- **루프 결속(Loop Closure)**: 장거리 주행 시 누적되는 오차를 해결하기 위해 Rao-Blackwellized 파티클 필터 기반 **FastSLAM** 및 그래프 기반 **GraphSLAM**을 적용, 이전에 방문했던 교차로 재진입 시 포즈 그래프(Pose Graph)를 최적화하여 왜곡 없는 글로벌 맵 완성.

### 1.3 Voronoi Diagram &amp; Medial Axis Transform 기반 복도 무충돌 경로 계획
- **물류 통로(Aisle) 중심 최적화**: 지게차나 AMR이 좁은 통로를 주행할 때 벽면이나 적재물에 근접 주행 시 동적 충돌 위험이 급증함.
- **기하학적 경로 생성 및 스택**: 점유 격자 지도 장애물들 사이의 등거리 궤적인 **보로노이 다이어그램(Voronoi Diagram)**과 **내측축 변환(Medial Axis Transform)**을 생성하고, 이를 탐색 그래프의 간선(Edge)으로 채택. 로봇이 복도의 정중앙 경로를 우선 추종하도록 유도하여 코너 회전 시 회전 반경 여유를 최대화하고, 실시간 국소 장애물 출현 시 **Grid Search (A*, Dijkstra)** 및 **RRT***, **ROS Navigation Stack / Nav2** 기반 동적 우회 경로 생성.

### 1.4 Dronus-Net6: 3D LiDAR SLAM 화물 인양/하역 &amp; 50km/h PID 외란 제어
- **3D 화물 인양 및 하역장(Drop-off Zone) 자율 투하**: 3D LiDAR 포인트클라우드 실시간 매핑을 통해 중량 화물(Cargo)의 상부 도킹 포인트를 탐색/인양하고, 지정된 안전 하역 구역(Drop-off Zone)까지 자율 복귀하여 **10cm 이내 오차로 안전 투하 완료**.
- **50km/h PID 자세 복원 루프**: 급기동 시 기체 자세가 무너지지 않도록 **Cascaded PID (Position → Velocity → Attitude → Rate)** 제어 루프를 재설계 ($u(t) = K_p e(t) + K_i \int e(\tau)d\tau + K_d \frac{de(t)}{dt} + K_{ff} a_{target}$). 발사/외란 반동 충격을 0.2초 이내에 선제 억제하고 수평 복원.
- **고압 CO2 6연발 리볼버 액추에이터 펌웨어 임베딩**: 고압 솔레노이드 밸브 펄스 구동 타이밍 드라이버를 비행제어기 펌웨어 내 인터럽트 서비스 루틴(ISR)으로 직결 구현하여 MAVLink 페이로드 명령의 결정론적(Deterministic) 동기화 격발.

### 1.5 Direct RF vs 4G/5G 셀룰러 제어권 중재기 (Control Authority Arbiter)
- **기능 안전(Functional Safety) 인터럽트**: 안전 요원이 물리 조종기(ELRS 250Hz / TBS CRSF) 스틱을 15% 이상 변위시킬 경우, 이를 하드웨어 인터럽트로 감지하여 **15ms 이내에 4G/5G 자율 명령을 즉시 무효화하고 Direct RF 수동 조종으로 강제 절체**. 제어 충돌 위험을 선제 방지.

## 2. 요가큐(YogaQ): 온디바이스 컴퓨터 비전 AI (Hailo-8L) &amp; 3D 공간 기하 보정 아키텍처
> **온디바이스 엣지 AI와 기하학적 좌표 보정을 결합하여 클라우드 의존성 제로화와 실시간 3D 인식을 실현한 핵심 설계 결정 (비중 35%)**  
> **기술 실증 아키텍처**: [pf7.eggs.or.kr](https://pf7.eggs.or.kr)

### 2.1 클라우드 GPU의 한계와 2단계 분리 가속 (Two-Stage Decoupled Perception)
- **시스템 인프라 및 기술적 당면 과제**: 고해상도 비디오 스트림을 중앙 클라우드로 전송 시 대역폭 병목과 카메라 1대당 **월 $720의 인프라 비용** 및 네트워크 단절 시 제어 불가 위험이 발생함.
- **2단계 분리 가속 파이프라인**: Stage-1 비전 백본은 13 TOPS Hailo-8L NPU(YOLOv8s-Pose 20.4ms)에서 처리하고, Stage-2 분류기는 ARM Cortex-A76 CPU에서 순수 NumPy 연산(0.018ms)으로 직결. 소형 텐서의 PCIe DMA 버스 왕복 오버헤드(0.5ms) 대비 CPU 직접 연산이 **25배 빠른 초저지연** 달성 (33.4 FPS 실시간 추론 완결).

### 2.2 광학 왜곡 극복: Safe Torso Scale Guard &amp; 디바운서
- **Safe Torso Scale Guard (크로스 도메인 브리지)**: 단일 2D 카메라 급각도 원근 왜곡에 따른 25배 좌표 발산을 하한 클램핑($\text{scale}=\max(H_{\text{torso}}, 0.250 \cdot ref)$, $max\_abs < 4.81$)으로 억제하는 Safe Torso Scale Guard 설계 — 협소 통로 주행 및 급기동 시 3D 객체/파렛트 포켓 인식 안정화에 직결.
- **마르코프 5-프레임 디바운서**: 전이 구간 채터링을 완충하여 99.9% 확정 상태 잠금.

### 2.3 초저지연 하이브리드 RAG &amp; 인프라 경량화 (Zero Cloud Egress)
- **$140 단일 어플라이언스**: RPi5 + NPU + 광각 카메라를 PoE 단일 케이블로 구동하여 **월 GPU 인프라 $0.00 달성** (Zero Cloud Egress). 중앙 클라우드 GPU 연산 부하 0(O(1) 선형 확장성)을 실측 검증.
